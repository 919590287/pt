# Issue Tracker

Issues and specs live in this repository's Gitee Issues.

## Conventions

- Use the Gitee web interface to create, view, comment on, label, and close issues.
- Reference issues as `#<number>`.
- No dedicated CLI workflow is assumed.

## Pull requests as a request surface

External pull requests are not a triage request surface for this repository.

## When a skill says "publish to the issue tracker"

Create a Gitee issue in this repository.

## When a skill says "fetch the relevant ticket"

Open the referenced issue in this repository's Gitee Issues.
